# Farm-Management-System

# Conceptual Knowledge:

Hey,
This project is been designed for agriculture purpose where farmers can keep track of there agro products.

This project contains:

1. Authentication system
2. Farmers Registration
3. CRUD Operation
4. Seeds wise Records
5. Adding agro products by farmers
6. Triggers
7. View Records
8 Sell Agro Products

# Requirements Modules Open command prompt and download these below modules

1. pip install flask
2. pip install Flask-SQLAlchemy
3. pip install mysqlclient
4. pip install Flask-Login
